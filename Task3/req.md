# Требования безопасности

В данном случае все зависит от возможностей подрядчика.

Если устройству для моментального распознавания лиц/номеров машин требуется хранить список фото/номеров локально, то необходимо, чтобы подрядчик обеспечил:

*   биометрическая информация хранится в виде сигнатур, номера машиy — в виде хэшей без возможности восстановить исходное фото/номер
*   биометрические шаблоны никак не привязаны к ИД пользователя
*   биометрические шаблоны могут быть удалены по запросу пользователя

В противном случае вся информация для доступа через распознавание (лиц, номеров) должна хранится в контуре компнии prop, что накладывает определенные ограничения на функционирование системы.

Дополнительные требования для интеграции:

*   **Аутентификация:**  
    OAuth 2.0 или OpenID Connect для обмена токенами (JWT) с ограниченным сроком действия. 
*   **Авторизация и контроль доступа:** Применение principle of least privilege: конкретный токен дает доступ только для необходимых действий (например, открыть шлагбаум)
*   **Сетевое взаимодействие** по HTTPS с TLS 1.3.  
    Шифрование payloads с помощью AES-256
*   для хранения биометрии использовать сертифицированные криптосредства по 152-ФЗ
